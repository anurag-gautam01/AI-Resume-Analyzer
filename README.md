# 🚀 AI Resume Analyzer Pro

An AI-powered web application that analyzes resumes, calculates ATS scores, compares resumes with job descriptions, and provides personalized improvement suggestions to help users build recruiter-friendly resumes.

> ⚠️ This project is currently in development and new features are being added continuously.

---

## 📌 Overview

AI Resume Analyzer Pro helps students, freshers, and professionals improve their resumes using Artificial Intelligence. The application extracts resume details, identifies missing skills, checks ATS compatibility, and suggests improvements based on industry standards and job requirements.

The platform is designed to simplify the resume optimization process and increase the chances of getting shortlisted during recruitment.

---

## ✨ Features

- 📄 Upload Resume in PDF Format
- 🤖 AI-Based Resume Analysis
- 📊 ATS Score Generation
- 🧠 Skill Extraction & Matching
- 🔍 Resume vs Job Description Comparison
- 📌 Missing Keywords Detection
- 💡 Personalized Improvement Suggestions
- 🌙 Dark Mode Support
- 🔐 User Authentication
- 📱 Fully Responsive UI
- 🕘 Resume Analysis History

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/AI-Resume-Analyzer-Pro.git
```

### 2️⃣ Navigate to Project

```bash
cd AI-Resume-Analyzer-Pro
```

---

## ▶️ Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

## ▶️ Backend Setup

```bash
cd server
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `server` folder.

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_api_key
```
